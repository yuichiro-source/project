# MTG自己分析

お客様とのMTGの文字起こしを貼り付けると、Claude が **良かった点 / 改善点（箇条書き）** と **10点満点の採点** を出し、過去と **同じミスをしていればアラート** を出す管理画面です。

## 使い方

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm start            # http://localhost:3000
```

API キーなしで画面だけ確認したい場合は `npm run mock`（ダミー分析、データは `data-mock/` に保存）。

### 入力欄
| 項目 | 内容 |
|---|---|
| クライアント名 | 必須。過去に入力した名前は候補に出ます |
| MTG種別 | オリエン / 中間 / プレゼン / その他（種別ごとに評価観点が変わります） |
| MTG名・日付 | 任意 |
| 文字起こし | テキスト貼り付け、または Google ドキュメント URL |
| 自分の話者名（右上） | 文字起こし上の自分の名前。一度入れるとブラウザに保存されます |

Google ドキュメントは共有設定を「リンクを知っている全員（閲覧者）」にしてください。

### 機能
- **採点**: 総合点（10点満点）＋ ヒアリング / 提案・説明 / 進行 / 合意形成 の4項目
- **良かった点・改善点**: 各5〜10個を目安に具体的な箇条書き。改善点には「次回どうするか」付き
- **同じミスのアラート**: 改善点はミスの種類（例: 予算のヒアリング漏れ）に分類され、過去のMTGと同じ種類が出ると赤く警告。前回のMTGも表示
- **よくあるミス**: 回数順ランキング
- 一覧の絞り込み（クライアント名・種別）、結果のテキストコピー、削除

## 構成
- `server.js` — Express API（`/api/meetings`）
- `lib/analyze.js` — Claude API 呼び出し（構造化出力で JSON を取得）
- `lib/gdoc.js` — Google ドキュメントのテキスト取得
- `lib/store.js` — `data/meetings.json` への保存
- `public/` — 画面（1ページ、ビルド不要）

環境変数: `ANTHROPIC_API_KEY`（必須）、`PORT`（既定 3000）、`DATA_DIR`（既定 `./data`）、`CLAUDE_MODEL`（既定 `claude-opus-5-5`）
